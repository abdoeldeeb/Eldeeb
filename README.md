# نظام إدارة الطلبات - Order Management System

نظام شامل لإدارة الطلبات والسجلات باللغة العربية مع دعم كامل للـ RTL وواجهة مستخدم عصرية.

## 🏗️ هيكل المشروع

```
order-management-system/
├── index.html                 # الصفحة الرئيسية
├── README.md                  # ملف التوثيق
├── order-management-records.html  # النسخة الكاملة (للمرجع)
└── assets/
    ├── css/
    │   └── styles.css        # ملف التنسيقات المخصصة
    └── js/
        ├── config.js         # الإعدادات والثوابت
        ├── data.js           # إدارة البيانات والطلبات
        ├── utils.js          # الوظائف المساعدة
        ├── ui.js             # إدارة واجهة المستخدم
        ├── modals.js         # إدارة النوافذ المنبثقة
        ├── table.js          # إدارة الجداول والترقيم
        ├── filters.js        # نظام الفلترة والبحث
        ├── notifications.js  # نظام الإشعارات
        └── app.js            # الملف الرئيسي للتطبيق
```

## 📋 الميزات الرئيسية

### 🎨 واجهة المستخدم
- ✅ دعم كامل للغة العربية (RTL)
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ✅ نظام ألوان عصري مع تدرجات جذابة
- ✅ أيقونات SVG عالية الجودة
- ✅ رسوم متحركة ناعمة

### 📊 إدارة البيانات
- ✅ إضافة وتعديل وحذف الطلبات
- ✅ نظام حالات متقدم (قيد المراجعة، قيد المعالجة، مكتملة، مرفوضة، تحتاج مراجعة)
- ✅ تصنيف الطلبات حسب نوع الخدمة
- ✅ نظام أولويات (عالية، متوسطة، منخفضة)
- ✅ حفظ البيانات في التخزين المحلي

### 🔍 البحث والفلترة
- ✅ بحث متقدم في جميع حقول الطلب
- ✅ فلترة حسب الحالة، نوع الخدمة، التاريخ
- ✅ ترتيب البيانات حسب أي عمود
- ✅ عرض مرن للنتائج (10، 25، 50، 100 سجل)

### 📈 الإحصائيات والتقارير
- ✅ لوحة معلومات تفاعلية
- ✅ إحصائيات فورية للطلبات
- ✅ تصدير البيانات إلى CSV

### 📱 التوافق والأداء

- ✅ محسن للأجهزة المحمولة
- ✅ أداء سريع ومحسن
- ✅ دعم الطباعة

## 🚀 كيفية التشغيل

### المتطلبات الأساسية
- متصفح ويب حديث (Chrome، Firefox، Safari، Edge)
- لا يحتاج إلى خادم - يعمل محلياً

### خطوات التشغيل
1. **تحميل الملفات:**
   ```bash
   git clone [repository-url]
   cd order-management-system
   ```

2. **فتح الموقع:**
   - افتح ملف `index.html` في متصفحك المفضل
   - أو استخدم خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 8000
   
   # باستخدام Node.js
   npx serve .
   ```

3. **بدء الاستخدام:**
   - ستجد بيانات تجريبية جاهزة للتجربة
   - يمكنك إضافة طلبات جديدة من خلال زر "طلب جديد"

## 🔧 التطوير والتحسين

### إضافة ميزات جديدة

3. اربطها مع واجهة المستخدم في `ui.js`
4. أضف التنسيقات في `styles.css`

- استخدم أدوات المطور في المتصفح

## 🐛 استكشاف الأخطاء

### مشاكل شائعة وحلولها

#### البيانات لا تظهر
- تأكد من تحميل جميع ملفات JavaScript
- افحص وحدة التحكم للأخطاء
- تأكد من دعم المتصفح للـ localStorage

#### الترقيم لا يعمل
- تأكد من تحميل ملف `table.js`
- افحص قيم `filteredOrders` و `currentPage`

#### الفلترة لا تعمل
- تأكد من تحميل ملف `filters.js`
- افحص وظيفة `filterOrders()`

#### مشاكل التنسيق
- تأكد من تحميل ملف `styles.css`
- افحص إعدادات RTL
- تأكد من تحميل خط Tajawal
